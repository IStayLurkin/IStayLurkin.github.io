# IStayLurkin.github.io

Personal portfolio and developer profile website, hosted for free on **GitHub Pages**.

🔗 **Live Website**: [https://istaylurkin.github.io](https://istaylurkin.github.io)

---

## 🚀 Features

- **Blazing Fast**: Pure HTML5, CSS3, and modern vanilla JavaScript with zero external frameworks or heavy dependencies.
- **Theme Support**: Seamless dark and light modes with localStorage persistence and system preference detection.
- **Responsive**: Fully optimized for mobile, tablet, and desktop screens.
- **Accessible & SEO Friendly**: Semantic markup, meta tags, and high-contrast color scheme.

---

## 🛠️ How to Customize

1. **Profile & Bio**: Edit `index.html` to update your name, tagline, and the **About Me** section.
2. **Skills & Projects**: Add or modify your projects and tech stack tags directly inside the `<section id="skills">` and `<section id="projects">` sections in `index.html`.
3. **Contact Links**: Update your GitHub, LinkedIn, email, or other social profiles inside the **Contact** and **Hero** sections.
4. **Colors & Styling**: Tweak CSS variables in `styles.css` (e.g. `--accent`, `--bg-primary`) to change the color palette.

---

## 📦 Local Preview

You can open `index.html` directly in any web browser, or serve it using any local static server:

```powershell
# Using Python
python -m http.server 8000

# Using Node / npx
npx serve .
```
